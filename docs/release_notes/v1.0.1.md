# Spice v1.0.1 (Jan 28, 2024)

Spice v1.0.1 is the first release since the 1.0 version of Spice.ai OSS. This release includes bug fixes and minor improvements focusing on better user experience.

## Highlights in v1.0-stable

- **Improvement to `spice upgrade` command**: The `spice upgrade` command will uses the updated spice cli to upgrade spiced.
- **Glue support for Iceberg Catalog Connector**: Iceberg Catalog Connector now supports connection to AWS Glue catalog.
- **Automatic GPU acceleration for local development**: When running locally via standard install methods with AI enabled, the Spice runtime will automatically detect if GPU acceleration via CUDA or Metal is supported and enable it.
