# Spice v1.2.1 (May 5, 2025)

Spice v1.2.1 includes M2M OAuth support for Databricks, important improvements for Iceberg data connector including cross-account Iceberg datasets support and reflecting data changes. It also improves parameterized query handling, adds federation support for accelerated views data refresh for better performance, and introduces support for metadata columns in object-store based data connectors.

## Highlights v1.2.1

- **M2M OAuth for Databricks**: Use Databricks Service Principal (M2M OAuth) to connnect to Spark or Delta Lake Databricks dataset or catalogs.

- **Metadata columns for object-store**: Configure object-store data connectors (i.e. s3, file) to expose querable metadata columns: `location`, `last_modified`, `size`

```yaml
datasets:
  - from: s3://company-data-warehouse/sales_data
    name: sales_data
    params:
      file_format: parquet
    metadata:
      location: enabled
      last_modified: enabled
      size: enabled
```

```sql
SELECT * FROM sales_data WHERE location = 'tenant_id=1234/year=2025/month=05/sales.parquet' AND transaction_id = 98765;
```

- **Improved Parameterized Query Support**: Enhanced handling and type inference for placeholders in:
  - `IN` list expressions
  - `LIKE` patterns
  - `SIMILAR TO` patterns
  - `LIMIT` clauses
  - Subqueries

## Upgrading

To upgrade to v1.2.1, use one of the following methods:

**CLI**:

```console
spice upgrade
```

**Homebrew**:

```console
brew upgrade spiceai/spiceai/spice
```

**Docker**:

Pull the `spiceai/spiceai:1.2.1` image:

```console
docker pull spiceai/spiceai:1.2.1
```

For available tags, see [DockerHub](https://hub.docker.com/r/spiceai/spiceai/tags).

**Helm**:

```console
helm repo update
helm upgrade spiceai spiceai/spiceai
```
