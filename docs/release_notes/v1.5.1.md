# Spice v1.5.1 (July 28, 2025)

Spice v1.5.1 includes

## What's New in v1.5.1

**Github comments in Github PR dataset**: Configure Github pulls datasets to include comments
```yaml
datasets:
  - from: github:github.com/spiceai/spiceai/pulls
    name: spiceai.pulls
    params:
      include_comments: all # 'none', 'review', 'discussion', or 'none'. Defaults to 'none'.
      max_comments_fetched: 42 # Default: 100
      # ...
```

**Rate Limiting for AWS Bedrock models**: Improve rate limiting for AWS embedding models by enabling users to configure a `max_concurrent_invocations`.
```yaml
version: v1
kind: Spicepod
name: ILoveBedrock

embeddings:
    - from: bedrock:cohere.embed-english-v3
      name: cohere-embeddings
      params:
          max_concurrent_invocations: '41'
          # ...
```

**Improved partition pruning**: Increased support for partition pruning functionality including support for more inequality operators (e.g. >, >=, <, <=).

**Support client-side cache keys**: Support for X-Spice-Cache-Key headers in the HTTP and Arrow Flight SQL query APIs to for finer-grained client-side caching control.
```bash
$ curl -vvS -XPOST http://localhost:8090/v1/sql \
-H"x-spice-cache-key: 1851400_20170216_north_america" \
-d "select * from scihub_journals_accessed
    where user_id = '1851400'
      and date_trunc('DAY', timestamp) = '2017-02-16'
      and city = 'New York';"
```
