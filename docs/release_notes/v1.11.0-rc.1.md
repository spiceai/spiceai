# Spice v1.11.0-rc.1 (Jan 5, 2025)

v1.11.0-rc.1 is a release candidate for early testing of v1.11 features including OTel metrics exporter, Google LLM support, SMB and NFS data connectors, prepared statements, distributed query cluster mode with mTLS, and various performance improvements.

## What's New in v1.11.0-rc.1

### OTel Metrics Push Exporter

Spice now supports pushing metrics to OpenTelemetry collectors, enabling seamless integration with your existing observability infrastructure.

### Google LLM Support

Added support for Google embedding and chat models, expanding the available LLM providers for AI inference workloads.

### SMB and NFS Data Connectors

New data connectors for SMB (Server Message Block) and NFS (Network File System) protocols, enabling direct access to network-attached storage.

### Prepared Statements

Added support for prepared statements, improving query performance and security for parameterized queries.

### Distributed Query Cluster Mode with mTLS

Distributed query cluster mode now requires mTLS for secure communication between executors and schedulers. The `spice cluster tls` commands help manage TLS certificates for cluster deployments.

### Cayenne Accelerator Improvements

- Added S3 Express One Zone support for data files
- Improved deletion vectors with KeyBased support

### Developer Experience Improvements

- Added `spice cloud` CLI commands
- Added `dataset_load_parallelism` parameter for parallel dataset loading
- Improved spicepod JSON schema generation
- Added snapshot interval configuration for acceleration snapshots

## Upgrading

To try v1.11.0-rc.1, use one of the following methods:

**CLI**:

```console
spice upgrade --version 1.11.0-rc.1
```

**Homebrew**:

```console
brew upgrade spiceai/spiceai/spice
```

**Docker**:

Pull the `spiceai/spiceai:1.11.0-rc.1` image:

```console
docker pull spiceai/spiceai:1.11.0-rc.1
```

For available tags, see [DockerHub](https://hub.docker.com/r/spiceai/spiceai/tags).

**Helm**:

```console
helm repo update
helm upgrade spiceai spiceai/spiceai --version 1.11.0-rc.1
```

**AWS Marketplace**:

🎉 Spice is available in the [AWS Marketplace](https://aws.amazon.com/marketplace/pp/prodview-jmf6jskjvnq7i/).
