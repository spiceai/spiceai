# Spice v2.3.4 (October 26, 2026)

Spice v2.3.4 is a security patch release. It fixes CVE-2026-111497, an out-of-bounds write in the Brotli decoder of the DuckDB that Spice bundles. A malformed Brotli-compressed Parquet file can trigger the write when DuckDB reads it, for example through the DuckDB data connector or the DuckDB accelerator. Upgrade if DuckDB in your deployment can read Parquet files that you do not control. The release also fixes stale cached results for parameterized queries in some cache setups. No configuration changes are needed.

## What's New in v2.3.4

### Brotli Decoder Fix in the Bundled DuckDB (CVE-2026-111497)

DuckDB no longer writes out of bounds when it decodes a malformed Brotli-compressed Parquet page. The decoder now rejects an invalid block switch with the `BROTLI_DECODER_ERROR_FORMAT_BLOCK_SWITCH` error. Before this release, the decoder continued with stale block-type state, and a crafted file could make it write outside its buffer.

Most Parquet reads in Spice do not go through DuckDB. The fix matters where DuckDB itself decodes a Parquet file that an untrusted party can supply.

Spice builds DuckDB v1.4.4 from source, so this release carries the fix before a DuckDB release includes it. The fix is a port of [duckdb/duckdb#27791](https://github.com/duckdb/duckdb/pull/27791), which ports [google/brotli@0ed4268a](https://github.com/google/brotli/commit/0ed4268a4401abcb4472096340477cf4af7d1a2b).

### Cached Results for Parameterized Queries Are Refreshed Again

Spice now refreshes a stale cached result for a parameterized query in the background, as `stale_while_revalidate_ttl` specifies. This affected two setups: `cache_key_type: sql`, and a client that sends the `Spice-Cache-Key` header.

Before this release, the background query lost the parameter values and failed with `Placeholder '$1' was not provided a value for execution`. Spice then served the stale result for the full `item_ttl` plus `stale_while_revalidate_ttl` window. Each stale request also started another background query that failed. The results were old, but not wrong.

### Dependency Updates

- `duckdb-rs` (Spice fork): `76655d2f` → `320c6d1b`. The bundled DuckDB stays at v1.4.4 and adds the Brotli decoder fix.
- `datafusion-table-providers` (Spice fork): `b10ae96a` → `1c48bcf6`. The only change is the `duckdb-rs` update.

DataFusion remains at v54.1.0 and Arrow remains at v58.3.0.

## Upgrading

To upgrade to v2.3.4, use one of the following methods:

**CLI**:

```console
spice upgrade
```

**Homebrew**:

```console
brew upgrade spiceai/spiceai/spice
```

**Docker**:

Pull the `spiceai/spiceai:2.3.4` image:

```console
docker pull spiceai/spiceai:2.3.4
```

For available tags, see [DockerHub](https://hub.docker.com/r/spiceai/spiceai/tags).

**Helm**:

```console
helm repo update
helm upgrade spiceai spiceai/spiceai --version 2.3.4
```

**AWS Marketplace**:

Spice is available in the [AWS Marketplace](https://aws.amazon.com/marketplace/pp/prodview-jmf6jskjvnq7i).
