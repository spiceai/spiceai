# Spice v1.5.2 (Augusst 4, 2025)

Spice v1.5.2 provider a new AWS Bedrock Models Provider for converse API compatible models, AWS Redshift support for the Postgres data connector, and additional Hadoop Catalog Support for Iceberg tables.

## What's New in v1.5.2

**AWS Bedrock Models Provider**: Adds a new Amazon Bedrock LLM Provider. Models that are compatible with the [Converse API](https://docs.aws.amazon.com/bedrock/latest/APIReference/API_runtime_Converse.html) are supported.

Example Spicepod.yaml:

```yaml
models:
  - from: bedrock:us.amazon.nova-lite-v1:0
    name: novash
    params:
      aws_region: us-east-1
      aws_access_key_id: ${ secrets:AWS_ACCESS_KEY_ID }
      aws_secret_access_key: ${ secrets:AWS_SECRET_ACCESS_KEY }

      bedrock_guardrail_identifier: arn:aws:bedrock:abcdefg012927:0123456789876:guardrail/hello
      bedrock_guardrail_version: DRAFT
      bedrock_trace: enabled

      bedrock_temperature: 42
```

**AWS Redshift Support for Postgres Data Connector**: Use the Postgres data connector in Spice to connect to tables in AWS Redshift.
  
**Additional Hadoop Catalog Support for Iceberg**: Adds support for `file://`, `s3://` and `s3a://` Hadoop Catalog endpoints as both a Data Connector and Catalog Connector with Iceberg.

Example Spicepod.yaml:

```yaml
version: v1
kind: Spicepod
name: hadoop
catalogs:
  - from: iceberg:file:///tmp/hadoop_warehouse/
    name: local_hadoop
datasets:
  - from: iceberg:file:///tmp/hadoop_warehouse/test/my_table_1
    name: local_hadoop
```

## Upgrading

To upgrade to v1.5.2, use one of the following methods:

**CLI**:

```console
spice upgrade
```

**Homebrew**:

```console
brew upgrade spiceai/spiceai/spice
```

**Docker**:

Pull the `spiceai/spiceai:1.5.2` image:

```console
docker pull spiceai/spiceai:1.5.2
```

For available tags, see [DockerHub](https://hub.docker.com/r/spiceai/spiceai/tags).

**Helm**:

```console
helm repo update
helm upgrade spiceai spiceai/spiceai
```
