# Spice v1.9.2 (Nov 26, 2025)

v1.9.2 fixes a bug in cache metrics which prevented them from being properly emitted.

# Cache Metrics

Once you enable caching in `spicepod.yaml`:
```yaml
runtime:
  caching:
    sql_results:
      enabled: true
```

You can now fetch `results_cache_*` metrics:

```bash

> curl -s http://localhost:9090/metrics | grep "^# HELP" | awk '{print $3}' | sort -u | grep results_cache_

results_cache_hit_ratio
results_cache_items_count
results_cache_max_size_bytes
results_cache_misses
results_cache_requests
results_cache_size_bytes
```

## Upgrading

To upgrade to v1.9.2 use one of the following methods:

**CLI**:

```console
spice upgrade
```

**Homebrew**:

```console
brew upgrade spiceai/spiceai/spice
```

**Docker**:

Pull the `spiceai/spiceai:1.9.2` image:

```console
docker pull spiceai/spiceai:1.9.2
```

For available tags, see [DockerHub](https://hub.docker.com/r/spiceai/spiceai/tags).

**Helm**:

```console
helm repo update
helm upgrade spiceai spiceai/spiceai
```
