# Spice v1.10.0-rc1 (Dec 2, 2025)

v1.10.0-rc1 is a release candidate focused on smarter caching, higher-throughput distributed execution, richer connectors, and tighter runtime hardening on the path to v1.10.0 GA.

## What's New in v1.10.0-rc1

### Smarter Caching with SWR and TinyLFU

This release introduces a new `caching` acceleration mode that implements the stale-while-revalidate (SWR) pattern, allowing queries to return cached results immediately while asynchronously refreshing data in the background. Combined with the new TinyLFU cache eviction policy, Spice can now maintain higher cache hit rates while keeping memory usage predictable.

### Enhanced Distributed Query Execution

Distributed query planning and execution have been significantly improved:
- Fixed executor registration in cluster mode for more reliable distributed deployments
- Improved hostname resolution for Flight server binding, enabling better executor discovery
- Added distributed registration support for data accelerators
- Optimized `DistributeFileScanOptimizer` for faster query planning with large datasets

### DynamoDB Streams Support

A new `dynamodb-streams` connector enables real-time streaming from DynamoDB tables, with support for both table bootstrapping and continuous change data capture (CDC).

### Connector and Acceleration Enhancements

- **S3 location predicate pruning**: Dramatically reduces data scanned by pushing down predicates to S3 listing operations
- **AWS S3 Tables write support**: Full read/write capability for AWS S3 Tables
- **Cayenne improvements**: Added `sort_columns` configuration for optimized inserts and `file_create` mode for accelerators
- **DuckDB aggregate pushdown**: Pushes aggregate operations down to DuckDB for faster query execution

### Security and Hardening

Multiple security improvements have been landed:
- SQL identifier quoting hardening across all connectors to prevent injection attacks
- Token redaction in debug output to prevent credential leakage
- Path traversal prevention in tar extraction
- Input sanitization and validation for `top_n_sample` order_by parsing
- Improved credential handling in Glue connector

### Search Improvements

- Fixed FTS query blocking issues for better query responsiveness
- Optimized vector index operations to avoid unnecessary `list_vectors` calls
- Improved `IndexerExec` to properly handle limit pushdown for more efficient searches

### Developer Experience

- Added health probe latency metrics for better observability
- Improved `.clear history` command in the CLI
- Better error handling with stricter clippy lints
- Enhanced testoperator with query-only execution mode and append benchmarking

## Upgrading

To try v1.10.0-rc1, use one of the following methods:

**CLI**:

```console
spice upgrade --version 1.10.0-rc1
```

**Homebrew**:

```console
brew upgrade spiceai/spiceai/spice
```

**Docker**:

Pull the `spiceai/spiceai:1.10.0-rc1` image:

```console
docker pull spiceai/spiceai:1.10.0-rc1
```

For available tags, see [DockerHub](https://hub.docker.com/r/spiceai/spiceai/tags).

**Helm**:

```console
helm repo update
helm upgrade spiceai spiceai/spiceai --version 1.10.0-rc1
```

**AWS Marketplace**:

🎉 Spice is available in the [AWS Marketplace](https://aws.amazon.com/marketplace/pp/prodview-jmf6jskjvnq7i/).
