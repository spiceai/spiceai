# Spice v1.10.1 (Dec 15th, 2025)

v1.10.1 introduces new Github data connector datasets for Github action workflows, several improvements for Cayenne, and improvements to the security posture. 

## What's New in v1.10.1

### New Github Workflow datasets

Add support for retrieving workflow, workflow run and workflow logs for Github repositories. 

```yaml
datasets:
  - from: github:github.com/spiceai/spiceai/workflows/testoperator_run_bench.yml/runs
    name: benchmark_runs
    params:
      github_token: ${secrets:GITHUB_TOKEN}
      github_workflow_logs: enabled # Include logs from workflow runs. 
```

### Cayenne Improvements

Several improvements and bug fixes for the Cayenne accelerator

- **Improve Vortex defaults**: Align Cayenne to Vortex footer configuration.
- **Enable Compression strategies**: On Cayenne accelerators, the `cayenne_compression_strategy` parameter can decide between compact storage `zstd` and encoding efficient `btrblocks` strategy.
- **Improve incrementing IDs**: Improve partition IDs to avoid possible locking race conditions. 

### Security Hardening

Multiple security improvements have been implemented:

- **Limit user-provided object depths**: Add limits to DynamoDB and S3 Vectors integrations to prevent stack overflow from deeply nested structures.
- **Return spicepod summaries from `v1/spicepods`**:  Avoid possible secret leakage from `spicepod.yaml`s by limiting information returned from GET `v1/spicepods`.

## Breaking Changes
 - GET `/v1/spicepods` no longer returns an entire `spicepod.yaml` JSON representation. A summary is returned, see [#8404](https://github.com/spiceai/spiceai/pull/8404).

## Cookbook Updates

No major cookbook updates. The [Spice Cookbook](https://spiceai.org/cookbook) still offers 82+ recipes to help you prototype quickly.

## Upgrading

To try v1.10.1, use one of the following methods:

**CLI**:

```console
spice upgrade --version 1.10.1
```

**Homebrew**:

```console
brew upgrade spiceai/spiceai/spice
```

**Docker**:

Pull the `spiceai/spiceai:1.10.1` image:

```console
docker pull spiceai/spiceai:1.10.1
```

For available tags, see [DockerHub](https://hub.docker.com/r/spiceai/spiceai/tags).

**Helm**:

```console
helm repo update
helm upgrade spiceai spiceai/spiceai --version 1.10.1
```

**AWS Marketplace**:

🎉 Spice is available in the [AWS Marketplace](https://aws.amazon.com/marketplace/pp/prodview-jmf6jskjvnq7i/).
