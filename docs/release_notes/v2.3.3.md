# Spice v2.3.3 (October 21, 2026)

Spice v2.3.3 is a security patch release. It updates the library Spice uses to validate TLS certificates and the root certificates bundled with it, so Spice stops trusting certificates issued under the [eMudhra intermediate CAs whose private keys were reported compromised](https://blog.cloudflare.com/emudhra-certificate-compromise/). No configuration changes are needed.

## What's New in v2.3.3

### Updated TLS Certificate Trust

- **Certificate validation**: `rustls-webpki` 0.103.16 rejects a certificate chain that passes through a CA key that is no longer trusted, including cross-signed copies of that key. This applies whenever Spice verifies a certificate with rustls, whether it uses the bundled root certificates or the operating system's.
- **Bundled root certificates**: `webpki-roots` and `webpki-root-certs` 1.0.10 follow Mozilla's current root store, which no longer includes "emSign ECC Root CA - G3".
- **Operating system trust store**: connections made through OpenSSL or `native-tls` use the operating system's trust store, so these updates do not change them. The v2.3.3 Docker images are built with an updated `ca-certificates` package that removes "emSign ECC Root CA - G3" and "Comodo AAA Services root". If you run Spice outside Docker, update your operating system's `ca-certificates` package.

### Dependency Updates

- `rustls-webpki`: 0.103.13 → 0.103.16
- `webpki-roots` and `webpki-root-certs`: 1.0.7 → 1.0.10

DataFusion remains at v54.1.0 and Arrow remains at v58.3.0.

## Upgrading

To upgrade to v2.3.3, use one of the following methods:

**CLI**:

```console
spice upgrade
```

**Homebrew**:

```console
brew upgrade spiceai/spiceai/spice
```

**Docker**:

Pull the `spiceai/spiceai:2.3.3` image:

```console
docker pull spiceai/spiceai:2.3.3
```

For available tags, see [DockerHub](https://hub.docker.com/r/spiceai/spiceai/tags).

**Helm**:

```console
helm repo update
helm upgrade spiceai spiceai/spiceai --version 2.3.3
```

**AWS Marketplace**:

Spice is available in the [AWS Marketplace](https://aws.amazon.com/marketplace/pp/prodview-jmf6jskjvnq7i).
