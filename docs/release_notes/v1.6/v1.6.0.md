# Spice v1.6.0 (Aug 25, 2025)

Spice 1.6.0 upgrades DataFusion to v48 for improved performance and memory usage. The release introduces OpenAI Responses API support for advanced model interactions, enhanced OpenAI Embeddings Connector with usage tier configuration for higher throughput, and adds support for Model2Vec embeddings for ultra-low-latency encoding. Improved S3 Vectors now support multi-column primary keys. It expands data connectivity capabilities with new connectors for Kafka and MongoDB, enabling real-time streaming and NoSQL data acceleration.

## What's New in v1.6.0

## DataFusion v48 Highlights

Spice.ai is built on the DataFusion query engine. The v48 release brings:

**Performance & Size Improvements 🚀**: Expressions memory footprint was reduced by ~50% resulting in faster planning and lower memory usage. There are now fewer unnecessary projections in queries. The string fuctions, `ascii` and `character_length` were optimized for improved performance. Queries with unbounded aggregate window functions have improved performance by 5.6 times!

**New Features & Enhancements ✨**: Support was added for `ORDER BY ALL` allowing for easy ordering of all columns in a query. User‑defined aggregate and window functions can cross FFI boundaries, enabling shared libraries to exchange those functions. 

See the [Apache DataFusion 48.0.0 Changelog](https://github.com/apache/datafusion/blob/main/dev/changelog/48.0.0.md) for details.

### Runtime Highlights

**Improved primary key support in S3 Vectors:** The S3 vectors index integration in Spice now supports datasets with multi-column primary keys.

**OpenAI Embeddings Connector Usage Tier:** The OpenAI Embeddings Connector now supports specifying account usage tier for embeddings requests, improving the performance of generating text embeddings during dataset load and search by increasing concurrent embeddings requests.

Example spicepod.yml:

```yaml
embeddings:
  - from: openai:text-embedding-3-small
    name: openai_embed
    params:
      openai_usage_tier: tier1
```

By setting the usage tier to the matching usage tier for your OpenAI account, the Embeddings Connector will increase the maximum number of concurrent requests to match the specified tier.

For more information, refer to the [OpenAI Embeddings Connector documentation](https://spiceai.org/docs/components/embeddings/openai)

**Model2Vec embeddings**: Expanded support for static model2vec embeddings in Spicepod definitions, for scenarios requiring low-ms latency during encoding.

```yaml
embeddings:
  - from: model2vec:minishlab/potion-base-8M
    name: potion
  - from: model2vec:path/to/my/local/model
    name: local
```

**Kafka Data Connector**: Use `from: kafka` to ingest data directly from Kafka topics for seamless integration with existing Kafka-based event streaming infrastructure, allowing real-time data acceleration and analytics without additional middleware.

Example `Spicepod.yml`:

```yaml
- from: kafka:orders_events
  name: orders
  acceleration: 
    enabled: true
    refresh_mode: append
  params: 
    kafka_bootstrap_servers: server:9092
```

Learn more in the [Kafka Data Connector documentation](https://spiceai.org/docs/components/data-connectors/kafka).

**MongoDB Data Connector**: Use `from: mongodb:` to access and accelerate data stored in MongoDB storage, deployed on-premises or in the cloud.

Example `spicepod.yml`:

```yaml
datasets:
  - from: mongodb:my_dataset
    name: my_dataset
    params:
      mongodb_host: localhost
      mongodb_db: my_database
      mongodb_user: my_user
      mongodb_pass: password
```

See the [MongoDB Data Connector documentation](https://spiceai.org/docs/components/data-connectors/mongodb).

**OpenAI Responses API Support**: Spice OSS now supports the OpenAI Responses API (`/v1/responses`), which is OpenAI's most advanced interface for generating model responses.

You can now make requests to any compatible model using the standard responses endpoint.

Example `curl` request:

```shell
curl http://localhost:8090/v1/responses \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4.1",
    "input": "Tell me a three sentence bedtime story about Spice AI."
  }'
```

To make requests to the OpenAI Responses API from `spice chat`, use the `--responses` flag.

Example:
```bash
spice chat --responses # Use the `/v1/responses` endpoint for all completions instead of `/v1/chat/completions`
```

Use [tools](https://platform.openai.com/docs/api-reference/responses/create#responses_create-tools) supported by Open AI's Responses API by specifying the `openai_responses_tools` parameter:
```yaml
models:
    - name: test
      from: openai:gpt-4.1
      params:
          openai_api_key: ${ secrets:SPICE_OPENAI_API_KEY }
          tools: sql, list_datasets
          openai_responses_tools: web_search, local_shell #  'local_shell', 'code_interpreter', or 'web_search'
```
These OpenAI-specific tools are only available from the `/v1/responses` endpoint. Any other tools specified via the `tools` parameter are available from both the `/v1/chat/completions` and `/v1/responses` endpoints.
