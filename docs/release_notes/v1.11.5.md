# Spice v1.11.5 (Mar 30, 2026)

Spice v1.11.5 is a patch release improving **`on_zero_results: use_source`** fallback performance, **Delta Lake** timestamp predicate data skipping, fixing **PostgreSQL** partitioned table schema discovery, and preparing the CLI for v2.0 runtime upgrades.

## What's New in v1.11.5

### `on_zero_results: use_source` Fallback Performance Improvement

Improved the [`on_zero_results: use_source`](https://spiceai.org/docs/features/data-acceleration/data-refresh#behavior-on-zero-results) fallback path to run DataFusion's physical optimizer on the federated scan plan ([#9927](https://github.com/spiceai/spiceai/pull/9927)). The fallback path now runs `SessionState::physical_optimizers()` rules on the federated scan plan before execution, enabling parallel file group scanning and other optimizations. This results in significantly faster fallback queries on multi-core machines, particularly for file-based data sources like Delta Lake.

### Delta Lake: Fix Data Skipping for `>=` Timestamp Predicates

Fixed an issue in the [Delta Lake](https://spiceai.org/docs/components/data-connectors/delta-lake) data connector where data skipping (file-level pruning) did not work correctly for `>=` timestamp predicates ([#9932](https://github.com/spiceai/spiceai/pull/9932)). Delta Lake table scans with `>=` timestamp filters now correctly prune files that do not match the predicate, improving query performance.

### PostgreSQL: Fix Partitioned Tables Support

Fixed an issue where the [PostgreSQL](https://spiceai.org/docs/components/data-connectors/postgres) data connector did not discover the schema for [partitioned tables](https://www.postgresql.org/docs/current/ddl-partitioning.html) ([#9997](https://github.com/spiceai/spiceai/pull/9997)). PostgreSQL partitioned tables are now fully supported for federated and accelerated queries.

## Upgrading

To upgrade to v1.11.5, use one of the following methods:

**CLI**:

```console
spice upgrade
```

**Homebrew**:

```console
brew upgrade spiceai/spiceai/spice
```

**Docker**:

Pull the `spiceai/spiceai:1.11.5` image:

```console
docker pull spiceai/spiceai:1.11.5
```

For available tags, see [DockerHub](https://hub.docker.com/r/spiceai/spiceai/tags).

**Helm**:

```console
helm repo update
helm upgrade spiceai spiceai/spiceai --version 1.11.5
```

**AWS Marketplace**:

Spice is available in the [AWS Marketplace](https://aws.amazon.com/marketplace/pp/prodview-jmf6jskjvnq7i).
