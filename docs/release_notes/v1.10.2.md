# Spice v1.10.2 (Dec 22, 2025)

v1.10.2 introduces tiered caching with localpod, periodic acceleration snapshots, DynamoDB column consolidation into JSON, and Kafka/Debezium batching for faster ingestion. Also includes fixes for SQLite accelerator decimal/date handling and real-time status reporting for `/v1/datasets` and `/v1/models` API endpoints.

## Highlights

- **Tiered Caching with Localpod**: Localpod connector now supports caching refresh mode, enabling tiered acceleration where a persistent cache (e.g., file-mode DuckDB) feeds a fast in-memory cache (e.g., memory-mode DuckDB). New cache entries automatically propagate to child accelerators, and children initialize from existing parent data on startup.

```yaml
datasets:
  # Parent: persistent file-mode cache
  - from: https://api.example.com
    name: api_cache
    acceleration:
      enabled: true
      refresh_mode: caching
      engine: duckdb
      mode: file

  # Child: fast in-memory cache fed by parent
  - from: localpod:api_cache
    name: api_cache_memory
    acceleration:
      enabled: true
      refresh_mode: caching
      engine: duckdb
      mode: memory
  ```

- **Acceleration Snapshots**: New `snapshots_create_interval` parameter enables periodic snapshot creation for accelerated datasets across all refresh modes.

```yaml
acceleration:
  enabled: true
  engine: duckdb
  mode: file
  refresh_mode: caching
  snapshots: enabled
  params:
    snapshots_create_interval: 60s # Write a snapshot every 60 seconds
  ```

- **DynamoDB JSON Nesting**: Consolidate columns into a single JSON column using the `json_object: "*"` metadata option. Useful when only a few columns are needed as discrete fields. See [DynamoDB JSON Nesting](https://spiceai.org/docs/components/data-connectors/dynamodb#json-nesting) for details.

```yaml
datasets:
  - from: dynamodb:my_table
    name: my_table
    columns:
      - name: PK
      - name: SK
      - name: data_json
        metadata:
          json_object: "*"  # Captures all other columns as JSON
```

- **Kafka/Debezium Batching**: Configure message batching for Kafka and Debezium connectors for faster data ingestion.

  ```yaml
  datasets:
    - from: debezium:kafka-server.public.my_table
      name: my_table
      params:
        batch_max_size: 10000    # Max records per batch (default: 10000)
        batch_max_duration: 1s   # Max wait time per batch (default: 1s)
  ```

## Upgrading

To upgrade to v1.10.2, use one of the following methods:

**CLI**:

```console
spice upgrade
```

**Homebrew**:

```console
brew upgrade spiceai/spiceai/spice
```

**Docker**:

Pull the `spiceai/spiceai:1.10.2` image:

```console
docker pull spiceai/spiceai:1.10.2
```

For available tags, see [DockerHub](https://hub.docker.com/r/spiceai/spiceai/tags).

**Helm**:

```console
helm repo update
helm upgrade spiceai spiceai/spiceai
```

**AWS Marketplace**:

🎉 Spice is now available in the [AWS Marketplace](https://aws.amazon.com/marketplace/pp/prodview-jmf6jskjvnq7i)!
