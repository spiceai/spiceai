# Spice v1.11.1 (Feb 9, 2026)

v1.11.1 is a patch release improving **Cayenne accelerator** reliability, enhancing **DynamoDB** and **HTTP** data connectors, and fixing issues in **Federated Task History** and **FlightSQL**.

## What's New in v1.11.1

### Cayenne Accelerator Improvements

This release includes critical fixes for the Cayenne accelerator:

- **Row-based Deletion Logic**: Improved logic for row-based deletes to ensure correctness.
- **Constraints & On Conflict**: Proper support for `constraints` and `on_conflict` configurations in Cayenne.
- **Partitioned Table Deletion**: Fixed support for deleting from partitioned Cayenne tables.
- **Data Integrity**: Fixed issues with protected snapshots during cleanup to prevent data loss.

### Data Connector Improvements

- **DynamoDB Streams**: Improved bootstrapping for DynamoDB Streams tables.
- **HTTP Connector**: The HTTP data connector now returns all HTTP responses as data and correctly skips caching for 5xx errors.

### Other Improvements

- **Acceleration Snapshots**: Added retries for SnapshotManager and general reliability improvements.
- **Caching**: Fixed handling of timestamp precision mismatches in caching.
- **Federated Task History**: Fixed a double projection issue in federated task history queries that could cause errors.
- **FlightSQL**: Added cookie middleware support.

## Upgrading

To upgrade to v1.11.1, use one of the following methods:

**CLI**:

```console
spice upgrade
```

**Homebrew**:

```console
brew upgrade spiceai/spiceai/spice
```

**Docker**:

Pull the `spiceai/spiceai:1.11.1` image:

```console
docker pull spiceai/spiceai:1.11.1
```

For available tags, see [DockerHub](https://hub.docker.com/r/spiceai/spiceai/tags).

**Helm**:

```console
helm repo update
helm upgrade spiceai spiceai/spiceai --version 1.11.1
```

**AWS Marketplace**:

Spice is available in the [AWS Marketplace](https://aws.amazon.com/marketplace/pp/prodview-jmf6jskjvnq7i).
