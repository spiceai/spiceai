# Spice v0.20.0-beta (Nov 04, 2024)

Spice v0.20.0-beta improves the performance federated queries across multiple sources, adds support for Metal (Apple Silicon) and CUDA (NVIDIA) accelerators for AI workloads, and improves the schema inference for the PostgreSQL Data Connector. The `S3`, `PostgreSQL`, `MySQL`, and `GitHub` Data Connectors have graduated from `beta` to `release candidate`. The `Arrow`, `DuckDB`, and `SQLite` Data Accelerators have graduated from `alpha` to `beta`.

## Highlights in v0.20.0-beta

**Data Connectors:** The `S3`, `PostgreSQL`, `MySQL`, and `GitHub` Data Connectors have graduated from `beta` to `release candidate`.

**Data Accelerators:** The `Arrow`, `DuckDB`, and `SQLite` Data Accelerators have graduated from `alpha` to `beta`.

**Metal and CUDA:** Support for Metal (Apple Silicon) and CUDA (NVIDIA) accelerators for AI workloads such as embeddings calculations and local LLM chat inference.

## Breaking changes

- Datasets accelerated by file-mode DuckDB and SQLite accelerations can only be created within the current working directory relative to the Spice runtime.

Invalid `duckdb_file`:

```bash
duckdb_file: /tmp/my_data.db
```

Valid `duckdb_file`:

```bash
duckdb_file: ./my_data.db
```

- The ODBC Data Connector requires ODBC drivers specified in connection strings are installed on the system and registered in the ODBC driver manager.

Invalid connection string:

```bash
DRIVER={/path/to/driver.so};SERVER=localhost;DATABASE=master
```

Valid connection string:

```bash
DRIVER={My ODBC Driver};SERVER=localhost;DATABASE=master
```

Where `My ODBC Driver` is the name of an ODBC driver registered in the ODBC driver manager.
