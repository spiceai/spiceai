One table.
Writes and reads that never collide.

Cayenne is a lakehouse format over the Vortex columnar format. It sustains high-rate CDC ingestion and low-latency analytical scans on the same table — because the two paths are engineered never to contend. This is the tour of how. For the full reference, see the README.

The problem worth solving

Three goals most engines force you to trade.

Write throughput, read latency, data freshness — pick two. Cayenne refuses the trade. Click a corner to see the mechanism that protects it.

Write throughput

Small writes don't make small files

High-rate CDC bursts would normally produce a tiny data file each, crushing both the writer and every future scan. Cayenne absorbs them into an LSM level-0 tier instead — a metastore-resident memtable, or pure RAM under the CDC profile.

A scan unions three tiers, then filters by merge-on-read.

Mechanism · sequence numbers

The deletion index is a stack of runs. A cutoff skips the old ones.

Every mutation carries a sequence number. Deletions pile into sequence-tagged runs (oldest → newest). A protected-snapshot probe with cutoff S skips any run whose deletes can't be newer than S — so probe cost tracks recent writes, not total tombstones. Drag S.

Why it holds together

The two paths share state, but never block on it.

Everything above works because of three rules the whole engine obeys. They're why a writer and a reader never wait on the same byte.

rule 01

Publish wait-free

State readers touch — the listing table, protected snapshots, the tier handles — is swapped behind ArcSwap. A reader never locks; a writer never waits for a reader to finish.

rule 02

Work off the fence

The expensive parts of a write — encode, metastore I/O, checkpoint — run outside the listing fence. Only the instant of becoming visible happens under it.

rule 03

Visibility is one flip

Files are immutable; a write or compaction becomes visible by atomically flipping the current-snapshot pointer. There is no in-place mutation for a reader to catch mid-change.
